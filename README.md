# Skate Penguin 🐧🛹

A pixel-art desktop pet prototype. Pip is a skateboarding penguin who can be fed, played with, and put to sleep.

## Requirements
- Node.js 20 or newer
- macOS (prototype target)

## Run locally
```sh
npm install
npm start
```

## Current prototype
- Transparent, always-on-top desktop companion window
- Pixel-art penguin drawn in canvas
- Feed, play, and nap buttons
- Hunger, happiness, and energy stats
- Local save using browser storage
- Drag window by its title bar

## Planned
Sprite-sheet animations, skate movement, sound, inventory, unlockables, packaged macOS app.
